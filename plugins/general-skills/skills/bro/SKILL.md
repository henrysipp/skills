# Bro

Restate your last message. Stop using jargon and speak coherently. State it more
simply and concisely, like one human talking to another.

## Rules

- Restate only. Do no new work, run no tools, add no new claims.
- Cut every term of art. If a technical name is unavoidable, say what it does in
  the same breath.
- Short sentences. Plain words. No lists of caveats.
- Keep the substance, including bad news. Simpler does not mean softer.
- Aim for a few sentences. If the original was long, say the point and the
  consequence, drop the rest.
